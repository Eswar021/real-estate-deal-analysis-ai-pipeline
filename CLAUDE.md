# Repo Instructions

This repository has three main tracks:

- `app/t12_pipeline/`  — T12 mapping pipeline (Python, batch)
- `app/ui/`            — Django UI wrapping the T12 pipeline
- `app/intial_swot_pdf_prototype/`  — SWOT PDF prototype

Scoped instruction files — read the relevant one before planning or
implementing changes:

- `app/t12_pipeline/CLAUDE.md` for any pipeline work
- `app/ui/CLAUDE.md` for any Django UI work

There is currently no equivalent scoped instruction file for the SWOT track.
